ADPHC Field Inspection Mobile
================================
Files:
- index.html
- manifest.webmanifest
- sw.js
- icons/

For iPhone / Android:
1. Upload all files/folders to an HTTPS website (e.g. GitHub Pages).
2. Open index.html from Safari (iPhone) or Chrome (Android).
3. Allow Camera and Location permissions.
4. iPhone: Share > Add to Home Screen.
5. Android: browser menu > Add to Home screen / Install app.

Notes:
- GPS requires HTTPS.
- Camera capture works from the file input on supported mobile browsers.
- PDF uses the browser Print/Save-as-PDF flow.
- Image export uses the native Share sheet when available.
- Reports/drafts are stored locally on the device browser.
