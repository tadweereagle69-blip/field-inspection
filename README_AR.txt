2) ابحث عن:

3) استبدلها بمفتاح Gemini الخاص بك.
4) احفظ وارفع الملفات إلى GitHub.

مثال:
const GEMINI_API_KEY="AIzaYOUR_KEY_HERE";

إذا كان GitHub Repository أو GitHub Pages عامًا، يمكن استخراج المفتاح من كود الصفحة.
